# 🛒 বাজার দর | BazarDor

### A Bengali Grocery Price Tracking Website

**বাজার দর (BazarDor)** is a modern, responsive grocery price tracking website designed to help users monitor daily essential product prices in Bangladesh.

Users can explore grocery products by category, compare market prices, track price increases and decreases, and manage their personal profiles through a secure authentication system.

The website provides a user-friendly Bengali interface to make grocery price information easily accessible.

---

## 🚀 Technologies Used

- **Next.js 16** — React framework with App Router
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript
- **Tailwind CSS** — Responsive UI styling
- **Better Auth** — Authentication and session management
- **MongoDB Atlas** — Database for user information
- **Lucide React** — Modern UI icons
- **React Icons** — Social media icons
- **Hind Siliguri** — Bengali typography

---

## ✨ Key Features

### 1. 📊 Daily Grocery Price Tracking
- View current prices of essential grocery products.
- Track price increases and decreases compared to previous prices.
- Explore product prices in a clean, responsive card layout.

### 2. 🗂️ Category-Based Product Browsing
- Browse products across 8 grocery categories.
- View category-specific products using dynamic routes.
- Sort products by price for easier comparison.

### 3. 🏪 Market-Wise Price Comparison
- Explore detailed information about individual products.
- Compare minimum, maximum, and average market prices.
- View market-wise price information in a structured table.

### 4. 🔐 User Authentication
- Secure email and password authentication using Better Auth.
- Google and GitHub social login integration.
- Protected routes for product details and user profiles.
- Session-based authentication and logout functionality.

### 5. 👤 User Profile Management
- View user information, including name, email, and profile image.
- Update profile information.
- Manage account sessions and securely sign out.

## 📱 Responsive Design

BazarDor is designed to work smoothly across:

- Desktop
- Tablet
- Mobile

The interface uses the **Hind Siliguri** font to provide a comfortable Bengali reading experience.

---


## 🔒 Security

- User authentication is managed using Better Auth.
- MongoDB Atlas stores authentication-related user data.
- Protected routes restrict access to authenticated users.
- Environment variables keep sensitive credentials outside the source code.
